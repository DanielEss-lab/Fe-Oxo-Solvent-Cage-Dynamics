# Changelog

## 0.1.0

First code-only release assembled from the supplied Fe-oxo/TQACl working code.

- Retains configurable BGAN dimensions, custom reaction coordinates, direction,
  histogram/window controls, loop seeds, manual topology, and validation reports.
- Adds installable package metadata, command-line entry points, portable working
  directories, input checks, explicit overwrite controls, and run metadata.
- Adds generic reference-window summaries, plotting, and synthetic example generation.
- Includes system-specific independent validation and figure-generation scripts.
- Retains the upstream MIT license and documents source hashes and patches.
