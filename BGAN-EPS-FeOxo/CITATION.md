# Citation

When using this modified implementation, cite both the publication associated with
the repository distributing this release and the original BGAN-EPS method:

Shin, W.; Ran, X.; Yang, Z. J. Accelerated Entropic Path Sampling with a
Bidirectional Generative Adversarial Network. *The Journal of Physical Chemistry B*
**2023**, *127* (19), 4254–4260.
[DOI: 10.1021/acs.jpcb.3c01202](https://doi.org/10.1021/acs.jpcb.3c01202).

Original software: [https://github.com/rshin1209/bgan_eps](https://github.com/rshin1209/bgan_eps).

Identify the modified software as **BGAN-EPS-FeOxo, version 0.1.0** and include
the publication repository URL and archived release DOI when these have been
assigned. The manuscript title, authors, repository URL, and DOI were not supplied
when this package was assembled; they have not been inferred or invented.
